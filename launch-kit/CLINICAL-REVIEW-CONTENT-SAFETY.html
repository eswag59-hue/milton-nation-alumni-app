Content Safety Keyword List — Clinical Review

For the Reviewer

This document lists every keyword and phrase the Milton Nation app uses to detect content that may indicate user distress, substance use relapse, or imminent safety concern. When detected in a post, comment, or chat message, these phrases trigger one or more of:

  1. Show in-app crisis support resources (988, Crisis Text Line, SAMHSA, Milton FL/OH numbers)
  2. Push notification to admin / care team for review and outreach
  3. Route post or comment to admin moderation queue (not auto-published)

The system is designed to be aggressive on the side of safety — false positives cost an admin review; false negatives could miss a real crisis. The list below reflects that bias.

What we need from you: Sign off section by section, add any Milton-specific patterns we missed, and flag any phrases that don't apply to the Milton alumni population.

⚙ How the System Works

The detection pipeline that wraps every keyword in this document

Detection Pipeline (6 stages)

  1. Normalize. Lowercase, strip leet-speak (h3r0in → heroin), collapse repeated chars (suuuuicide → suuicide), remove obfuscation punctuation (k.i.l.l → kill).
  2. Emergency check. Phrases like "I need help" or "call 988" are treated as help-seeking, not harm — they surface crisis resources but don't penalize the user.
  3. Keyword match. Compare the normalized text against every phrase in this document. Word-boundary aware for single-word matches.
  4. Regex patterns. Multi-word grammar like "want / wanna / going to + harm verb + self".
  5. Negation downgrade. "I do NOT want to kill myself" → downgrade by one tier (e.g. high → medium).
  6. Time-immediacy elevation (NEW). "Tonight I'm going to..." → upgrade by one tier (e.g. medium → high). See last section.

Risk Tiers

TierTriggers
HighPush to admin team with elevated priority. Post is held for moderator review (not auto-published). User sees crisis resources sheet immediately.
MediumPush to admin team for review. Post is held for moderator approval. User sees crisis resources sheet.
LowLogged for admin awareness. Post may auto-publish (per author's track record). User does NOT see crisis sheet — just awareness flag in admin dashboard.

Categories

Six categories total. The original four (self-harm, drugs, alcohol, violence) are well-established. Eating disorder and domestic violence are new in this version based on the clinical reality that both heavily co-occur with substance use disorder. Please review the new categories with particular care.

Privacy note: Raw user text never leaves the device. The detection happens locally. Only metadata (category, risk level, count of matches) is sent to the server — never the user's actual words.

🆘 Emergency Help-Seeking + Time-Immediacy

Two special-purpose lists that modify how the system responds.

Emergency Help-Seeking Phrases (NEVER flag as harm)

When any of these appears, the system shows the crisis resources sheet (988, Crisis Text Line, SAMHSA, Milton FL/OH, 911) and notifies admins for follow-up — but does NOT penalize the user, hold their post, or flag it as harm. The user is reaching out for help; we want to surface help.

Time-Immediacy Markers (Risk Elevation)

When any of these appears anywhere in the same text as a risk match, the system elevates that match's risk by one tier (e.g. medium → high). Caps at high risk. Rationale: "I'm cutting tonight" is materially different from "I've thought about cutting before" — the time-boundedness signals imminent action.

Without time elevation: matches "cutting" → MEDIUM risk → admin sees notification within 1 hour.
With time elevation: matches "cutting" + sees "tonight" → upgrades to HIGH risk → push to admin with elevated priority, post held for review, crisis resources surfaced.
