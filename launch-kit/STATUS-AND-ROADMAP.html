The iOS App (Build 10)

What it is, how it works, current state

What it does

SwiftUI app for Milton Recovery Centers alumni. 5 tabs: Home (sobriety counter + daily quote + announcements + "I'm Struggling Today"), Community (posts + comments + likes), Meetings (Milton-curated + nearby NA via BMLT API), Chat (1:1 secure messaging with assigned care team), Profile (sobriety / badges / settings). Admin & super_admin roles add a dashboard for member approval, content moderation, and care-team assignment.

Twilio (SMS)

OTP delivery — current blocker

What it does

Sends the 6-digit OTP code to user phones during login. The only Twilio product we use is Programmable Messaging. Per-SMS cost ~$0.0083 + carrier fees.

Current state

✓
Twilio account exists and is configured. Account SID + Auth Token + sending number are set in Supabase secrets.
✗
BAA not yet signed. Required for HIPAA — phone numbers + Milton's recovery-treatment context = PHI. Without BAA, signing real users up is a HIPAA violation. This is the main public-launch blocker. Ready-to-send email is in launch-kit/TWILIO-BAA-SEND-NOW.md.
?
A2P 10DLC status unknown. US carriers (AT&T, Verizon, T-Mobile) require app-to-person SMS senders to register their "brand" and "campaign". Without it, carriers silently drop messages — no error, no delivery log. This is likely why yesterday's smoke test SMS didn't arrive. To check: log into Twilio Console.
?
Account tier (trial vs paid) unknown. BAA requires paid. Same — check console.

What you'll see in Twilio Console once logged in

  1. Billing sidebar → top of page tells you Trial vs Paid
  2. Messaging → Regulatory Compliance → A2P 10DLC → Brand status + Campaign status
  3. Monitor → Logs → Messaging → every SMS attempt with status (delivered, failed, undelivered)
  4. If you sent SMS yesterday: it appears here with delivery status. If status is "delivered" but you never got it on your phone → carrier filtering (10DLC issue). If status is "failed" → Twilio-side issue. If no log at all → Edge Function never reached Twilio.
