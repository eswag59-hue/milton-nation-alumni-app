**The iOS bug we fixed on 6/12:** `supabase-swift` SDK version 2.41.1 has a bug where `.insert(...).select().single()` does NOT set the `Accept: application/vnd.pgrst.object+json` header on the request. PostgREST then returns a JSON array (one element) instead of a single object. Swift's decoder throws `DecodingError.dataCorrupted("The data couldn't be read because it is missing.")` when it sees `[` where it expected `{`. The user-facing error is "Couldn't post. Please check your connection and try again."

Every `.insert().select().single()` call site in `Milton Nation Alumni App/Services/SupabaseDataService.swift` was affected: posts, comments, meetings, chat messages, announcements, sobriety_milestones. Same bug also broke device_tokens registration (no push notifications worked). All 6 sites were patched to decode as `[Type]` and take `.first`. Verified by curl: server is fine, the bug was 100% client-side.
