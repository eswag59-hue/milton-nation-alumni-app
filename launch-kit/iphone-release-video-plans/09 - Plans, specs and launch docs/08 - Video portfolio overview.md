# Milton Nation — Launch Video Portfolio Kit

A complete production kit for the launch video slate: **6 role-specific onboarding videos, 2 announcement films, and 4 hype/launch ads** — built for Higgsfield (or any AI video tool) + real app screen recordings.

Everything in here was extracted from the live app code on 2026-08-25, so colors, button labels, flows, and copy are exact.

| File | What it is |
|---|---|
| [`01-BRAND-KIT.md`](01-BRAND-KIT.md) | Colors (light/dark/Pantone), fonts, logo files + rules, voice & tone, guardrails, the fact sheet for scripts |
| [`02-RECORDING-SHOT-LISTS.md`](02-RECORDING-SHOT-LISTS.md) | Click-by-click screen-recording instructions per role — incl. the simulator workaround for the app's screen-capture block, and the honest Android plan |
| [`03-VIDEO-SCRIPTS.md`](03-VIDEO-SCRIPTS.md) | Full scripts: VO, on-screen text, timing, per video — plus the social caption pack |
| [`04-HIGGSFIELD-PROMPTS.md`](04-HIGGSFIELD-PROMPTS.md) | Ready-to-paste generation prompts (brand motion, b-roll, type cards) + per-video assembly recipes + compliance checklist |
| [`05-EZRA-CHECKLIST.md`](05-EZRA-CHECKLIST.md) | Ezra's step-by-step to-do list + open questions |
